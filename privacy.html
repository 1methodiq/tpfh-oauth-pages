Privacy Policy

TPFH Shorts Uploader · Last updated 30 September 2026

What the app is

TPFH Shorts Uploader is a private tool used by one person, the owner of the Too Pretty For History YouTube channel, to upload Shorts to that channel and read the channel's own analytics. It has no other users.

What Google data it accesses

The app asks for these Google OAuth scopes:

  • youtube.upload: upload videos and set their title, description, tags, thumbnail, privacy status and scheduled publish time.
  • youtube.readonly: read the channel's own video list and processing status.
  • yt-analytics.readonly: read view, watch-time and retention reports for the channel's own videos.

It does not read or write comments, playlists, subscriptions, or any other user's data.

How data is stored and shared

  • The OAuth token is stored only on the channel owner's own computer, in a file readable by that user alone.
  • Analytics numbers are stored locally in the owner's working files. Nothing is sent to any third party, sold, or used for advertising.
  • No data is used to train machine-learning or AI models.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file has the same effect.

Contact

Questions go to the developer contact e-mail listed on the app's Google consent screen.
