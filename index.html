TPFH Shorts Uploader

TPFH Shorts Uploader is a private, single-user tool that uploads YouTube Shorts to the Too Pretty For History channel and reads that channel's own analytics. It runs on the channel owner's computer and is not offered to anyone else.

It uses the YouTube Data API to upload videos as private or scheduled, and the YouTube Analytics API to read view and retention numbers for the channel's own videos. It cannot edit or delete videos, comments or channel settings.
